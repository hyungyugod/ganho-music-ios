## AI 슬롭 패턴 — 자동 감점 (해당 축 -1점/건)

| 패턴 | 감점 축 |
|---|---|
| 강제 언래핑 `!`·`as!` | 성능·안정성 (P0 가능) |
| `Timer.scheduledTimer`·게임 내 `asyncAfter` | 패턴 |
| 매직 넘버 하드코딩 | 패턴 |

| SPEC에 없는 독립 기능 | 기능 |

## 루브릭 A — 일반 기능 변경 (4축)

가중치: **패턴 35% / 게임로직 30% / 성능·안정성 20% / 기능 15%** · 합격선 **7.0**

- 패턴 8점 기준: 전 패턴 준수, P2 1~2건 이내 / 5점: 강제 언래핑 1건+ 또는 매직넘버 3건+
- 게임로직 8점: SpriteKit 패턴 준수·루프 정상 / 5점: Timer 사용 또는 dt 미적용
- 성능·안정성 8점: 크래시 원인 0·빌드 클린 / 5점: P0 1건+
- 기능 8점: SPEC 전 기능 + 예외 처리 / 5점: 기능 누락 1건+

## 루브릭 B — 그랜드 리팩토링 R-Phase (5축)

가중치: **패턴 20% / 기능 30% / 성능 20% / 시각 20% / 안정성 10%** · 합격선 **7.5**

- 기능 = SPEC에 복사된 해당 Phase 합격 게이트(00_MASTER_PLAN §4) 충족도. **정량 게이트 미충족 시 해당 축 6점 이하 강제.**
- 시각 = 03_UI_DESIGN_SYSTEM 토큰·수치 일치도 (R3~R5), 그 외 Phase는 회귀 없음 기준
- 성능 = 풀링·캐싱·노드 수·update 경로 할당 등 코드 검수 중심 (시뮬레이터 fps 한계 인정)

## 캘리브레이션 예시 (점수 분해 기준점)

- **9.0+**: 전 게이트 충족 + 빌드 클린 + P1 0건 + 증거(측정치) 완비. "잘 작동할 것 같다"는 9점 사유가 아니다.
- **7.5~8.5**: 게이트 충족, P1 1~2건 (구체 수정안 제시됨), 측정치 일부 누락
- **6.0~7.4**: 게이트 1개 미충족 또는 P1 3건+ — 같은 방향 재시도 (Case A)
- **5.0 미만**: 핵심 기능 미동작 또는 범위 계약 위반 — 방향 전환 (Case C)
- **점수 무관 불합격**: P0 1건+ (빌드 실패, 크래시 원인, 불변 조건 위반, 사용자 데이터 손실)

## 판정

- 합격: 루브릭별 합격선 이상 + P0 0건
- 불합격: 그 외 — "구체적 개선 지시"를 우선순위 순으로 명시 (generator가 그대로 실행 가능한 수준)

## 과잉 지적 방지

evaluator는 갭을 찾으라면 항상 찾아낸다. **정확성·SPEC 요구사항·불변 조건에 영향 없는 지적은 P2로 격리**하고 합격/불합격 판정에 사용하지 않는다. generator는 P2 중 취향성 항목을 사유와 함께 미반영할 수 있다.
