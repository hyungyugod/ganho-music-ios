## 업로드 매핑

## 참고
- ASC가 iPad에서 13"(2064×2752) 대신 12.9"(2048×2732)를 고집하면, 같은 방식으로 `sips -z 2048 2732`만 바꿔 재생성 가능(문의 시 알려주세요).
- 최소 1장이면 통과하지만, 5장 모두 올리면 스토어 노출이 좋다. 순서는 01→05 권장(인게임이 첫 장).
- 캡처는 시뮬레이터(iPhone 17 Pro Max / iPad Pro 13" M5) 직행부팅으로 생성. 실기기에서 최종 1회 눈으로 확인 권장.
