# 02_GAME_FEEL — 게임필·중독 루프 설계서 (R1·R2·R6·R7)

> 목표: "앱스토어 고급 게임을 하고 있다"는 체감. 수치는 기본값이며 ±20% 내 튜닝은 Generator 재량, 그 이상은 SPEC 갱신 필요.
> 모든 신규 수치 상수는 `FeelTuning`/`MetaTuning`에 정의한다 (매직넘버 금지).

---

## 1. 프레임 원칙 (R1)

- 모든 이동·타이머는 dt 기반 유지 (현 구조 양호). `lastUpdateTime` 리셋 패턴 유지.
- update 파이프라인 순서를 GameScene에 명시 고정: **input → player → AI → projectiles → collisions(콜백) → effects → camera → HUD → registry.compact()**.
- `FrameStats`(DEBUG): 1초 평균 frame time·노드 수를 좌상단 미니 라벨로 표시. 토글 가능.
- 예산: 인게임 평시 노드 ≤300, 동시 파티클 이미터 ≤8, update 내 힙 할당 0 지향.

## 2. 히트스톱 (R2 — 타격감의 핵심)

`HitstopController`가 `physicsWorld.speed`·`worldNode.isPaused`를 제어 (HUD·오버레이 제외):

| 이벤트 | 정지 시간 | 동반 연출 |
|---|---|---|
| 콤보 마일스톤 도달 (5·7·10·20) | 0.045s | 줌 펄스 §3 |
| F/청진기 피격 (게임오버) | 0.10s → 0.25s에 걸쳐 speed 0→1 복귀 | 플래시 + 셰이크 강 |
| 박병장 폭탄 섬광 | 0.12s | 풀스크린 플래시 |
| 변기(+2) 수집 | 0.03s | 스쿼시 |
| 일반 음표 수집 (R10 #8) | 0.015s | 미니 — 수집 "딱" 체감만, 흐름 유지 |

- ~~일반 음표 수집에는 히트스톱 없음~~ → **R10 갱신**: 미니 히트스톱 0.015s(≈1프레임) 추가
  (`FeelTuning.hitstopNoteCollect`). 콤보 마일스톤/변기와 겹치면 longer-wins 합성이 흡수.
- 중첩 요청 시 더 긴 쪽만 적용. `#if DEBUG` 토글로 on/off 비교 가능하게.

## 3. 카메라 v2 (R2) — `CameraDirector`

- **추적**: 현 follow 유지하되 지수 보간 `lerp(cam, player, 1 - exp(-8.5 * dt))` — 즉시 추적 대비 미세 관성. 맵 클램프 유지.
- **셰이크**: 기존 x축 전용 → x·y 동시, 감쇠형. 강도 3단: soft(±3px, 0.15s) / medium(±6px, 0.22s) / strong(±10px, 0.32s), 매 스텝 0.82배 감쇠. 게임오버=strong, 스킬 발동=medium, 텔레그래프 발사=soft.
- **줌 펄스**: 콤보 마일스톤 시 scale 1.0→1.015→1.0 (0.18s, easeOut). 박병장 등장 시 1.0→0.97→1.0 (0.5s).
- **방향성 킥**: 피격 시 투사체 진행 방향으로 4px 밀렸다 복귀 (0.12s). R10 U5 — 박병장 본 노드 진입 시작 시 좌향 킥 1회 추가 (`FeelTuning.R10.sergeantEntryKickDirection`).
- **박병장 데뷔 연출 (R10 U5)**: 컷씬 fadeIn 시점 전용 스팅어 `.sergeantDebut`(square G2→C3, 0.5s — 사전 렌더) + 토스트 스탬프 1.4→1.0 easeOutBack + 진입 좌향 킥 + 중앙 도달 시 .soft 셰이크 1회. 컷씬 0.4/1.4/0.4=2.2s·enter 1.2s/stay 8.0s/exit 1.5s 계약 불변.

## 4. 파티클 (R2) — SKEmitterNode 6종, `EffectDirector` 경유

코드로 이미터 생성 (`.sks` 파일 불필요). 텍스처는 2×2~4×4 단색 사각형 (픽셀 톤 유지, `TextureAtlasStore` 제공):

| 이펙트 | 트리거 | 명세 |
|---|---|---|
| collectBurst | 음표 수집 | 8~12개, 速 40~90px/s 방사, 0.35s, gold(#FFD23F), birthRate 일시 burst |
| comboAura | 콤보 ≥5 동안 | 플레이어 발밑, 4개/s 상승, 콤보 단계 색 (5=gold, 7=coral, 10+=violet) |
| deathBurst | 게임오버 | 24개, 0.6s, coral+white 혼합, 중력 -60 |
| skillSignature | 스킬 4종 발동 | 캐릭터 시그니처 색 §9, 형태는 스킬별 (돌진=후방 트레일, 워프=출발·도착 쌍둥이 burst, 소집=수렴 방향, 모범생=상승 하트 6개) |
| toiletSplash | 변기 수집 | 10개, mint, 0.3s |
| milestoneConfetti | 점수 마일스톤 배너 | 화면 상단에서 16개 낙하, 1.0s, 3색 혼합 |

각 이미터는 풀링 (`EffectDirector`가 사전 생성·재사용). 동시 이미터 8개 초과 시 우선순위 낮은 것부터 스킵.

## 5. 마이크로 모션 (R2)

- **트윈 라이브러리** (`Core/Tween.swift`): `SKAction.timingFunction` 래퍼로 `easeOutBack`·`easeOutCubic`·`easeInOutQuad`·`easeOutElastic` 제공. 이후 모든 UI/연출은 linear 금지(페이드 제외).
- **스쿼시&스트레치**: 플레이어 이동 시작 시 (0.92x, 1.08y) 0.08s → 복원; 정지 시 반대로. 음표는 수집 직전 1.15배 팝 후 소멸.
- **수집 자석感**: 음표가 플레이어 32px 내 진입 시 0.08s 동안 플레이어 쪽으로 흡인 후 수집 (입력 관용성 향상 — 판정 자체는 불변).
- **걷기 먼지**: 4걸음마다 발밑 2px 사각 2개 0.25s 페이드 (파티클 아님, 풀링 노드).
- **플레이어 속도 곡선 활성화**: dead code인 `baseSpeedEnd`를 구현 — 45초에 걸쳐 `baseSpeedStart → baseSpeedEnd` 선형 보간. `baseSpeedEnd = baseSpeedStart × 1.15` 기본값 (GameplayTuning).
- **입력**: ~~dpad 즉시성 유지(스무딩 추가 금지)~~ → **R10 U4 갱신**: 정지→이동 첫 입력은 즉시(지연 0) 유지하되, *이동 중 방향 급변만* 80ms 지수 스무딩(`GameplayTuning.dpadDirectionSmoothingDuration`) — `player.currentDirection` 경로 한정, dpad 원시값·스킬 돌진 방향·facing 콜백·해제 즉시 정지는 비스무딩. 스킬 버튼에 0.1s 입력 버퍼 (쿨다운 종료 직전 입력 허용).

## 6. 사운드·햅틱 (R2)

### ChiptuneSynth (프로시저럴 8비트 SFX — 외부 에셋 불필요)

AVAudioEngine + 사전 렌더 PCM 버퍼 (시작 시 전부 생성·캐시, 런타임 합성 금지):

| 이벤트 | 파형 | 주파수 | 길이 |
|---|---|---|---|
| 음표 수집 | square | C5에서 시작, **콤보 1단계당 +반음** (최대 +12) | 60ms |
| 변기 수집 | square 2음 | E5→G5 | 110ms |
| 콤보 마일스톤 | triangle 아르페지오 | C5-E5-G5 | 180ms |
| 콤보 끊김 | saw 하강 | G4→C4 | 150ms |
| 피격/게임오버 | noise+square 하강 | — | 400ms |
| UI 탭 | square | A5 | 35ms |
| 별 획득 (결과창) | triangle | C6 / E6 / G6 (별당) | 120ms |
| 카운트다운 틱/발사 | square | A4 / A5 | 50/200ms |

- 기존 시스템 사운드 ID 폴백 (AudioManager L32-33) **제거** — 전부 ChiptuneSynth로 대체.
- BGM은 기존 유지 (5초 긴박 rate 1.0→1.15 연출 유지, setRate는 변화 시에만 호출).
- 콤보 피치 상승은 음악 게임 정체성의 핵심 — 최우선 구현.

### 7-3. 캐릭터 언락 (별 기반으로 개편)

김간호 기본 해금. 정간호 ★3 / 건간호 ★8 / 임간호 ★15 / 이간호 ★24.
**기존 `CharacterUnlockRules`로 이미 해금된 사용자는 그대로 해금 유지** (마이그레이션: 기존 해금 상태 → 신규 규칙과 OR 결합). 잠금 캐릭터는 선택창에서 실루엣 + 요구 별 표시.

### 7-4. 일일 도전

- 시드 = `YYYYMMDD` (`SeededRandom`) → 모디파이어 1종 선택, 하루 동일.
- 모디파이어 풀 6종: ①스피드 나이트(적 속도 +20%) ②음표 러시(음표 스폰 1.5배·목표 +30%) ③소등(비네트 시야 축소) ④거울 병동(맵 좌우 반전) ⑤황금 변기(변기 점수 2배·스폰 +1) ⑥기합 충만(스킬 쿨다운 50%).
- 최초 클리어 보상: 해당 판 별 2배 적립 + 전용 배지. Start 씬에 오늘의 도전 칩 + 남은 시간 노출.

### 7-5. 업적 (16종, `AchievementStrip` 확장)

첫 졸업(첫 성공) / 콤보 10 / 콤보 20 / 풀콤보 졸업(끊김 0 성공) / 변기 마니아(한 판 변기 4개) / 박병장 목격 / 정공법(김간호로 hard 성공) / 스킬 마스터(4캐릭터 스킬 각 10회) / hard 전 캐릭터 성공 / 누적 음표 500 / 누적 음표 2,000 / 일일 도전 7회 / 3별 셀 5개 / 3별 셀 15개(올클리어) / 전 캐릭터 해금 / Lv10 도달.

### 7-6. 데이터 (`MetaProgressRepository`)

- UserDefaults 신규 키 (StorageKeys에 추가, 기존 키 불변): 별 15셀·XP·업적 셋·일일 도전 기록.
- 클라우드 동기화는 기존 `CloudSaveCoordinator` 경로에 **추가 필드로만** 합류 (스키마 호환 유지). 실패해도 로컬 우선.
- R6 합격 게이트: 재설치 전 데이터(최고기록·졸업) 손실 0 — 마이그레이션 단위 테스트 1파일.

## 8. 페이싱·난이도 곡선 (R7)

- **웨이브 마커**: 10s(첫 압박: 발사 간격 보간 가속 시작) / 25s(중반 피크: 음표 스폰 +1) / 38s(라스트 스퍼트: BGM rate 연출 시작점과 정렬).
- **near-miss 보너스**: F/청진기가 피격 없이 플레이어를 스치면(충돌 히트박스 가장자리 기준 10px 셸 통과 — R8 retune: 구 22px 중심거리 기준은 5판 실측 발화 0건·축정렬 한정 4~6px 대역·대각 사각지대로 폐기, 사용자 승인) "아슬!" 마이크로 팝업 + 콤보 타이머 리셋(연장) + 햅틱 0.3. 판당 상한 없음. 회피 플레이에 보상 부여 (risk/reward).
- **콤보 게이지 가시화**: HUD 콤보 칩 하단에 60×4px 게이지 — 2.5s 콤보 윈도우의 잔여를 선형 표시, 마지막 0.7s 코랄 점멸. (숨은 룰의 가시화 = 긴장 디자인)
- **리스크 가속**: 콤보 ≥7 동안 음표 스폰 간격 0.85배 (점수 기회·위험 동시 증가).
- **스트레치 골(여유 시에만, 별 30 해금)**: 엔드리스 모드 — 45초 후 계속, 10초마다 적 발사 간격 0.93배, 피격 시 종료. 별도 리더보드 셀.

## 9. 캐릭터 시그니처 컬러 (파티클·UI 공통)

`PixelPalette.swift`의 기존 캐릭터 픽셀 데이터에서 대표색을 추출해 `Palette.character(_:)` 토큰으로 고정 (Planner가 추출값을 SPEC에 기록). 용도: 스킬 파티클, 선택창 글로우, 카드 보더, 결과창 캐릭터 칩.
